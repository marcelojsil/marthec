🚀 INÍCIO RÁPIDO (5 MINUTOS)
────────────────────────────────────────────────────────────────────────────

1. INSTALAR
   $ npm install

2. CONFIGURAR
   $ cp .env.example .env.local
   Edite .env.local com:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
   - NEXT_PUBLIC_WHATSAPP_NUMBER

3. RODAR
   $ npm run dev
   Acesse: http://localhost:3000

4. TESTAR
   ✓ Modal de oferta abre automaticamente
   ✓ Botões "Solicitar Orçamento" funcionam
   ✓ Formulário envia para Supabase
   ✓ Botões flutuantes aparecem

5. DEPLOY
   $ npm run build
   Push para GitHub → Netlify faz deploy

🐛 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

❌ "NEXT_PUBLIC_SUPABASE_URL is not defined"
   ✓ Verifique .env.local
   ✓ Reinicie: Ctrl+C e npm run dev

❌ "Failed to insert into marthec_orcamento"
   ✓ Confirme que tabela foi criada no Supabase
   ✓ Verifique credenciais

❌ Botão WhatsApp não funciona
   ✓ Teste URL: https://wa.me/seu_numero
   ✓ Remove caracteres especiais do número

❌ Modal não abre
   ✓ Verifique console do navegador (F12)
   ✓ Procure por erros em vermelho

🚀 DEPLOY NO NETLIFY
────────────────────────────────────────────────────────────────────────────

1. FAZER PUSH PARA GITHUB
   $ git add .
   $ git commit -m "Initial commit"
   $ git push origin main

2. CONECTAR NETLIFY
   1. netlify.com → New site from Git
   2. Selecione seu repositório GitHub
   3. Deixe default build settings
   4. Deploy

3. ADICIONAR VARIÁVEIS
   Netlify Dashboard → Settings → Build & deploy → Environment
   Adicione:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
   - NEXT_PUBLIC_WHATSAPP_NUMBER

4. REDEPLOY
   Clique em "Redeploy" após adicionar variáveis
